# Заметки к редизайну get.asystem.ai (02.11.2026)

## Инвентарь предмета
1. Платформа для лицензированных криптообменников Кыргызстана; 9 обменников работают (живое число из API).
2. Каждому обменнику — отдельный сервер и база в Бишкеке (ДЦ, свой HPE), закон о ВА требует сервер в КР.
3. Регулятор: ГСФР (156 кодов подозрительности), Финнадзор (отчёты), закон 87/2018, ПКМ 739/2025.
4. Цены на витрине только в сомах по курсу НБ КР на сегодня (API отдаёт курс и дату) — живое.
5. Виджет обмена с курсом в реальном времени — живое.
6. Два настоящих видео интерфейса (обменник и канбан заявок), скриншоты админки.
7. Модулей 20, включаются тумблером; новые: Telegram сотрудникам, Jivo, выгрузка курсов для мониторингов, автокурс.
8. Порог комплаенс-холда 500 000 сом (реальный у клиента), заявка «№7 · #f097e928» — формат из продукта.
9. Лицензию получает сам обменник, софт/серверы/обновления ведём мы.
10. Запуск за недели: бриф → сервер → настройка → старт.
11. Демо-стенд demo.asystem.ai, чек-лист запуска /blueprint, статус /status.
12. Артефакт мира: заявка в админке (карточка со статусом, KYC, комплаенсом), реестр сделок для Финнадзора.

## Идея
На этой странице **карточка заявки в админке оператора — то, в чём владелец лицензии живёт каждый день —**
становится **закреплённой сценой: она не уходит с экрана, пока мимо проходят требования регулятора КР,
и на каждое отвечает сама.** Тест конкурента (Premium Exchanger, Box): они не скажут «сервер в КР,
ГСФР, Финнадзор, сомы по НБ КР». Идея наша.

**Живое:** виджет обмена с живым курсом и тариф в сомах по курсу НБ КР на сегодняшнюю дату.
Второе живое — в showcase: меняешь сумму клиента слева, карточка заявки справа пересчитывается.

## Аргумент (секция → утверждение → доказательство)
1. Hero: это платформа для криптообменника под лицензию КР → живой виджет на сцене, кнопка «Запросить демо».
2. Features: внутри KYC, Comply Core, отчёты, сервер в КР, бренд, API → фрагменты интерфейса на сцене и в панелях.
3. Showcase: клиент создаёт — вы проводите → редактируемая заявка слева, карточка оператора справа.
4. How it works: четыре стадии до старта → ползунок, фрагмент продукта в нужном состоянии.
5. Modules: 20 модулей, что в тарифе, что докупается → печатный лист каталога.
6. Proof: интеграции и 9 обменников → строка названий (без выдуманных логотипов).
7. Pricing: два тарифа и выкуп, в сомах по НБ КР → меню цен из API.
8. FAQ: ответы читаемым текстом.
9. CTA: одна фраза, одна кнопка.
10. Footer: продукт крупно + меню.
