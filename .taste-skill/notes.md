# Заметки к лендингу get.asystem.ai

## v3 — тёмный финтех (02.11.2026, ветка feat/landing-dark)

Эрмек отверг версию по направлению tasteskill «split stage» («кринж, начинаем с нуля») и выбрал
характер «тёмный финтех, премиум», инструменты на моё усмотрение: three.js, motion, Remotion-клипы,
ffmpeg, скиллы Эмиля Ковальски. Taste Skill дальше используется только как инспектор гигиены
(две строки заголовка, размер текста, контраст, переполнение), а не как арт-направление: панели
с линией 8 %, ярлыки стадий и аккордеон здесь осознанны.

**Решения.**
- Одна тема: тон шоурила #0B0C0A, панели одним тоном выше с линией 8 %, лайм только на действии и
  признаках модулей. Manrope + Inter. Контейнер 1200, радиусы 12–20.
- Герой: фон — шейдер (react-three-fiber, один полноэкранный треугольник, fbm-шум, лаймовый отблеск
  на гребнях; dpr ≤ 1.5, кадры только пока герой на экране, под reduced-motion один кадр); заголовок
  построчно поднимается из-под маски (motion, ease [0.23,1,0.32,1], 90ms между строками); под ним
  настоящая запись канбана заявок (orders.mp4, тёмная) с лёгким параллаксом.
- Возможности: бенто из шести панелей с живыми фрагментами интерфейса (KYC, комплаенс, отчёт,
  сервер, запись витрины, API), без иконок.
- Шоурил 30 с (Remotion, asystem-promo), стадии запуска со sticky-фрагментом (IntersectionObserver,
  AnimatePresence 280ms), каталог модулей панелями по категориям + запись маркетплейса (modules.mp4),
  три тарифа с живыми ценами в сомах, аккордеон вопросов (height+opacity 240ms), финальная панель с формой.
- Motion по правилам Эмиля: только transform/opacity, press scale(0.97) 160ms, вход секций 16px
  со стаггером 60ms, ничего не анимируется на клавиатурных действиях, reduced-motion везде.

**Грабли.** `overflow-x: hidden` на body ломает `position: sticky` → `overflow-x: clip`.
Длинная подпись кнопки в карточке тарифа не влезала → «Получить предложение».
Playwright MCP пишет файлы только в корень fiatex-exchange.

**Ассеты.** public/demos: orders.mp4 (тёмный канбан), exchange.mp4 (витрина в телефоне),
modules.mp4 и admin-loop.mp4 (из asystem-promo/out), video/showreel(.en).mp4; постеры в public/shots
сняты ffmpeg (`-ss 0.5 -frames:v 1`).
